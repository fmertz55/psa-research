# Research Reports

Narrative benchmark reports live next to the repository's machine-readable run
artifacts rather than in engineering plans.

- `benchmarks/`: valid or partially valid research records, organized by program.
- `quarantine/`: withdrawn, invalid, or unsafe-to-cite runs retained for audit.

A report in `quarantine/` must never be cited as current performance evidence. Moving
a report out of quarantine requires corrected inputs, a new immutable run artifact,
and an explicit supersession note; do not rewrite the original audit record.
