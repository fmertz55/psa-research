# Research

This area contains active research programs and paper sources. Research hypotheses,
blocking metrics, and benchmark experiments do not redefine production contracts.

- `papers/`: manuscript sources, publication triage, and claim-provenance records.
- `programs/`: current experimental programs and pre-run checklists.

Machine-readable run artifacts and narrative result reports live under `reports/`.
Publication claims require an immutable manifest, valid inputs, and a current
end-to-end evaluation where the claim is about application behavior.
